# OptionApp 界面设计说明

> 对应 Figma 文件：https://www.figma.com/design/tQb0ldzwnNv48pokX8zeFO
> 画布尺寸：1440 × 900（桌面 Web），深色金融终端风格。

## 一、应用外壳（Sidebar + Topbar）

所有登录后的界面共享同一套外壳：

- **左侧边栏（224px）**
  - 顶部 Logo「OptionApp / 场外期权交易平台」
  - 交易模式切换：普通 / 专家 / 销售（分段控件，高亮当前模式）
  - 导航：首页、交易大厅、持仓管理、询价中心、场外百科、行情、资讯
  - 底部：当前用户（王经理 · 当前模式 · 民营证券）
- **顶部栏（60px）**
  - 当前页面标题、全局搜索框
  - 右侧行情速览（沪深300 / 上证50 / 中证500）、用户头像

## 三、界面清单（13 屏）

1. **登录（Login）** — 居中登录卡片，账号/密码输入，登录按钮，协议提示。
2. **首页（Home）** — 问候语 + 4 张统计卡（持仓市值/今日盈亏/待处理询价/持仓合约），标的行情表 + 快捷操作 + 市场快讯。
3. **普通 · 买入（BuyVanilla）** — 标的/方向/期限选择，期权合约链（行权价/买价/卖价/隐含波动率/成交量），下单票（名义本金、预估权利金、提交）。
4. **普通 · 行权（Exercise）** — 可行权合约表（合约/行权价/到期日/持仓量/现价/内在价值/操作），行权时限提示。
5. **专家 · 交易台（ExpertTrading）** — 实时双向报价 RFQ，下单（结构：香草/价差/跨式/宽跨式 + Greeks），最近成交。
6. **专家 · 持仓（ExpertPositions）** — 汇总卡（总名义/净Delta/净Gamma/浮动盈亏），持仓明细表，组合风险监控（保证金/风险度/回撤预警）。
7. **销售 · 代理询价（SalesRfq）** — 发起询价表单，询价列表（状态：待报价/已报价/已成交），报价流对比。
8. **场外百科 · 列表（WikiList）** — 分类筛选（入门/期权策略/风险管理/希腊字母/法规），文章卡片网格。
9. **场外百科 · 详情（WikiDetail）** — 文章正文 + 目录侧栏。
10. **TradeX · 行情（Market）** — 指数概览卡，行情列表，日内走势柱状图。
11. **TradeX · 资讯（News）** — 分类筛选 + 新闻列表。
12. **账户 / 设置（Account）** — 个人信息，交易模式权限（普通/专家/销售开关），安全与通知。
13. **询价详情 / 成交单（RfqDetail）** — 询价信息，报价对比表，成交确认。

## 四、角色与模式映射

- **普通模式**（客户）：仅「买入香草」与「行权」。
- **专家模式**（自营/做市）：交易台、持仓、复杂结构。
- **销售模式**（销售/代理）：代理询价、报价流、成交确认。

模式切换位于侧栏顶部，导航项在不同模式间共享，但内容按角色权限区分。

## 五、可点击原型映射

`prototype/` 目录（本项目 `src/`）为 React + Vite + TypeScript 实现，与 Figma 逐屏对应：

- 每个 Figma 界面 → 一个路由页面（`src/pages.tsx`）
- 应用外壳 → `src/ui.tsx` 的 `Shell`
- mock 数据 → `src/data.ts`
- 设计 token → `src/styles.css` 的 CSS 变量

## 六、已知限制

- 本轮为 UI 原型，交易、报价、撮合均为本地 mock 数据，未接后端。
- TradeX 源码不在当前环境，行情/资讯以 TradeX 风格（深色终端）重绘，后续可接入真实 TradeX 组件。
- 全部 13 屏截图已导出至 `design/screenshots/`（`01-home` ~ `13-rfq-detail`，1440×900）。Figma 账号已升级为 Education/Student 套餐，解除 Starter 的 MCP 调用频率限制。
